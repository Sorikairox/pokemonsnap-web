## Done (one commit each)

1. **FlashRAM as a PI device** (4d0d64d): `src/os/osFlash.c` (the game's driver, partly modified from libultra, with
   ultralib's flash read-status / clear-status / write-buffer / reinit) is now compiled as game code (census:
   pc-replaced -> game); `port/save/flashram.c` models the Macronix MX_C chip behind `osEPiWriteIo` / `osEPiReadIo` /
   PI DMA (commands, status register, silicon id, array reads at devAddr x2, page buffer, sector / chip erase, page
   program ANDs); `pc_pi.c` routes DMAs on the flash handle there (its old high-level `osFlash*` replacements are
   gone). `port/save/save.c`: `port_save_load`, `port_save_poll`, `rtw_save_ptr/size/generation`. v0.tsv
   regenerated (osFlash.c's three void functions now have IDO rows).

   in clang order: the image held the flags and the 0x4C / 0x24 defaults at the wrong bits. LSB-first under
   `#ifdef PORT`.
3. **Harness options** (7f86f49): node `--save IN --save-out OUT`; run.mjs `--save IN`, image dumped to OUT/flash.fla
   after every retrace that wrote the flash; `[save]` log lines (in tasks.txt).
4. **snap_save.py** (e44e1a5): decode / check an image (version, the game's MD4 variant reimplemented, offsets,
   name, flags, scores, photo slots; spots word-swapped emulator files).
5. Docs: SAVE.md, this note, MEMORY.md flash paragraph.
